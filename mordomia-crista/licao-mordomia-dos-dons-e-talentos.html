Mordomia dos dons e talentos

Nenhum dom foi dado para uso privado — cada um recebeu o que recebeu com um propósito comunitário embutido.

Movimento 1
Para o que for útil

"Mas a manifestação do Espírito é dada a cada um para o que for útil." (1 Co 12:7)

O texto não deixa espaço para "dons que só existem para mim" — cada capacidade vem com uma finalidade voltada para os outros.

Movimento 3
Cada um segundo sua medida

"Cada um administre aos outros o dom como o recebeu, como bons despenseiros da multiforme graça de Deus." (1 Pe 4:10)

A palavra "despenseiros" (mordomos) é a ideia central desta categoria inteira: o dom não é posse, é responsabilidade emprestada.

Desfecho
O padrão revelado
1 Coríntios 12:7

A manifestação do Espírito é dada a cada um para o que for útil.

— Mordomia Cristã

O dom escondido não rende nada; o dom investido cresce e serve. A mordomia dos dons é decidir, hoje, qual dos dois caminhos seguir.
